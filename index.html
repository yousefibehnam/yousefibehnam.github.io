About me

I like questions with measurable answers: is this codebase getting harder to maintain? Why does the same network fault keep returning?

For my master’s thesis I built a static analysis framework that measures the structure of object‑oriented Java systems, and evaluated it across open‑source projects — work that earned the Distinguished Master’s Thesis Award.

Since 2012 I’ve been an IT engineer at the Telecommunication Company of Iran, where I keep enterprise network services running, dig into logs for root causes, and automate the routine with Python. Next, I want to bring these two sides together in research on reliable, data‑driven systems.

★ Award‑winning thesis

Static analysis framework for Java software quality

A tool that reads object‑oriented Java code, builds a model of its classes and relationships, and scores how maintainable it is.

  • Computes five Chidamber & Kemerer metrics: CBO, LCOM, RFC, DIT and WMC
  • Evaluated on multiple open‑source Java projects
  • Basis for two manuscripts currently in preparation
